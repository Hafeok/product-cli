# Frame categories used by this run

**The bundle does not define "frame category."** Gate B requires every question to be
recorded with "which frame category it concerns"; Gate C requires the four-column table
"per frame category". The term appears twice in `prompt.md`, is defined nowhere in it,
and appears in none of the four arrived inputs. Gate C further asks for the categories
"in a form comparable against the category list being enumerated independently for the
notation experiment" — a list this session has not been given and, under the
prohibitions, may not seek.

So **the category scheme below is invented by this session**, after the build, by
clustering the questions that actually arose. It is not a reading of the specification.
Any agreement with the independent list is a finding about convergence; any disagreement
may be a disagreement about categories or merely about vocabulary, and this run cannot
tell those apart. Q-02.

| # | Category | What falls in it |
|---|---|---|
| **F1** | Act identity & address | which act, at which address, and which determinations reach it |
| **F2** | Fact shape | the internal structure of a fact — fields, types, units, nullability |
| **F3** | Position & boundary | read/write position, internal/external/terminal, the provenance of a read |
| **F4** | Invariant & rejection | what the act may decline for, on what authority, and how the decline is named |
| **F5** | Payload & validation | the command message and the checking of it before the decision |
| **F6** | Authority & actor | who may perform the act |
| **F7** | Transport realisation | the HTTP surface and the mapping from outcome to response |
| **F8** | Role decomposition | which type plays which profile role, and what falls outside every role |
| **F9** | Effect & egress | where a written fact goes, and what persists it |
| **F10** | Identity & time | identifier minting, timestamps, the clock |
| **F11** | Lifecycle & concurrency | idempotency, repeat acts, what a completed act does to its ground |
| **F12** | Enforcement & evidence | which rules are checkable, by what instrument, and what counts as evidence |
| **F13** | Notation & process | the instrument itself — the schema, the gates, the meta-vocabulary, the run's own rules |

Thirteen. F13 is not a category of the domain; it is where questions about the scheme
land, and it turned out to be the second-largest bucket.
